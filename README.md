# MNSHomeVanta

A responsive Amazon-affiliate starter website for **MNSHomeVanta**.

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.

## Before publishing
1. Replace the four `YOUR_AMAZON_AFFILIATE_LINK_*` placeholders with your real Amazon Associate links.
2. Replace the legal placeholders in `impressum.html` and complete the privacy policy.
3. Add your own product photos and descriptions.
4. Add your Amazon Associates disclosure according to the program requirements.
5. Connect the site to your domain/hosting.

The design is intentionally dependency-free: HTML + CSS + vanilla JavaScript.
